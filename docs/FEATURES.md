# 📦 Feature Plan

## Phase 1 — Instagram AI Message Manager (MVP)

### 🤖 AI Auto-Reply Engine
- Answer customer DMs automatically using AI (GPT-4o based)
- Understand natural language questions: *"Is this available in black size M?"*
- Reply in the seller's tone and language (Turkish, English, etc.)
- 24/7 availability — no human needed overnight

### 📦 Stock / Inventory Integration
- Connect seller's stock system (Excel, Google Sheets, Shopify, WooCommerce)
- AI checks real-time stock before replying
- Smart replies: *"Black is out of stock, but white is available — want me to reserve it?"*
- Low stock alerts sent to seller

### 💬 Instagram DM Management
- Instagram Graph API integration (Meta Business)
- Unified inbox dashboard — view all conversations
- AI handles routine messages, escalates complex ones to seller
- Message tagging: order inquiry, complaint, compliment, pricing question

### 🛒 Order Flow Assistance
- Guide customer from inquiry → order confirmation
- Collect: size, color, delivery address
- Send order summary to seller
- Basic payment link integration (optional)

### 📊 Analytics Dashboard
- Messages received / replied / converted
- Top asked questions
- Response time stats
- Sales conversion from DMs

---

## Phase 2 — Facebook + WhatsApp Expansion

### Facebook Messenger AI
- Same AI engine applied to Facebook Page messages
- Comment monitoring — auto-reply to product comments *"DM sent!"*
- Facebook Shops integration

### WhatsApp Business AI
- WhatsApp Business API integration (Meta Cloud API)
- Automated replies to WhatsApp messages
- Broadcast messages to customer lists (promotions)
- Order status updates via WhatsApp

### Unified Inbox
- One dashboard for Instagram DM + Facebook Messenger + WhatsApp
- See all channels in one place
- Assign conversations to team members
