# 🤖 SMTX — Social Media AI Assistant

> AI-powered SaaS platform for Instagram, Facebook & WhatsApp sellers. Automate customer messages, check stock, manage orders — 24/7.

---

## 🚀 Product Vision

An AI-powered assistant for **Instagram / Facebook / WhatsApp sellers** that handles customer messages 24/7, checks live stock, and manages orders — so sellers never miss a sale.

## 🛠️ Tech Stack (Summary)

| Layer | Technology |
|---|---|
| Frontend | React / Next.js |
| Backend | Python (FastAPI) |
| AI | Azure OpenAI (GPT-4o) |
| Messaging | Meta Graph API |
| Database | Azure PostgreSQL + Redis |
| Hosting | Azure App Service / AKS |
| Auth | Azure AD B2C |
